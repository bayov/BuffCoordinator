# Buff Coordinator

Who buffs whom in your raid, for every class. Like PallyPower, but for
totems, buffs, shouts and debuffs too.

**Fully automatic.** Every blessing, totem, buff, aura and boss debuff is
assigned to the best player for it. The leader can override any assignment,
and the rest of the assignments work around the change. Everyone with the
addon sees the same assignments.

**One click buffs the next player who needs it**, and a red glow shows what's
missing, even in combat.

## Getting started

- Type `/bc` or click the minimap button to open the window.
- Optionally: Set a key for "next buff" under Key Bindings > AddOns.
